# Дез-Сити — ночной AI-консультант в WhatsApp

Автоматический помощник для компании ТОО «Дез-Сити» (Астана). Принимает обращения клиентов в WhatsApp вне рабочих часов, консультирует, собирает заявку, называет цену по прайсу и доводит до записи с предоплатой.

Собран на n8n Cloud. Модель — Google Gemini 3.1 Flash Lite.

---

## Как это работает

```
Клиент пишет в WhatsApp (+7 701 214 2472)
        │
        ▼
   Wazzup  ──webhook──►  n8n
        │
        ▼
  Проверка расписания и фильтры
        │
        ▼
  Контекст из amoCRM по номеру
        │
        ▼
  Gemini: ответ + этап диалога
        │
        ├──► Ответ клиенту через Wazzup API
        ├──► Сводка менеджеру в WhatsApp (при оплате)
        └──► Примечание в сделку amoCRM (при оплате)
```

Время работы: **Пн–Чт с 18:00 и Вт–Пт до 09:30**, часовой пояс `Asia/Almaty`. Пятница вечером, выходные и ночь на понедельник — молчание.

---

## Что умеет

- Двуязычие: приветствие на казахском и русском, дальше язык фиксируется по ответу клиента
- Память диалога — не переспрашивает уже сказанное
- Фильтр по городу: технические услуги только в Астане, консалтинг из любого города
- Прайс для частных клиентов, двухэтапный расчёт по клопам
- Оценка степени заражения
- Продажа закрепления времени за предоплату 3 000 ₸ со ссылкой на Kaspi
- Приём скриншота квитанции
- Сценарий по вентиляции: фото, видео трассы, расчёт специалистом

Подробности — в [`docs/rules-and-prompt.md`](docs/rules-and-prompt.md).

---

## Внимание: репозиторий должен быть приватным

В материалах есть данные, которые не следует публиковать:

- Полный прайс-лист компании
- Рабочая ссылка на оплату Kaspi
- Номер WhatsApp менеджера
- Домен amoCRM и структура интеграции

Ключи API в этих файлах отсутствуют — в n8n они хранятся отдельно и в workflow передаются только по идентификатору. Но при выгрузке JSON проверьте, что в нём нет секретов, прежде чем коммитить.

**Создавайте репозиторий как Private.**

## Известные ограничения

**Оплата не проверяется автоматически.** Статическая ссылка Kaspi не даёт обратного сигнала. Бот видит только факт прихода изображения и не может отличить настоящую квитанцию от чужого или старого скриншота. Сверку делает менеджер утром.

**Слоты 12:00, 15:00 и 18:00 зашиты жёстко.** Бот не знает реальной занятости бригад и может предложить занятое время.

**История диалогов хранится в статических данных workflow.** Переживает перезапуски, но может обнулиться при серьёзных операциях на стороне n8n Cloud. Для продакшена стоит перенести в таблицу данных.

**Задержка ответа 30–40 секунд.** Обработка в n8n занимает 1,5–3,5 секунды, остальное — доставка Wazzup → WhatsApp. Средствами бота не лечится.

**Вложения не анализируются.** Бот не видит фото и не слышит голосовые, только подтверждает получение и передаёт специалисту.
